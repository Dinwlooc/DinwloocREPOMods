# SuperEnergy

**为游戏提供全面的能量管理功能：自动充电、玩家自愈、死亡复活、体力加速、滑铲效能提升。**  
所有功能均可独立开关，并支持多种能量来源（免费或消耗卡车电量/医疗包）。

---

## 前置依赖

- **[BepInEx](https://github.com/BepInEx/BepInEx/releases)** – 模组加载框架（≥ 5.4.2100）
- **[REPO_Dinwlooc_Lib](../REPO_Dinwlooc_Lib)** – 公共依赖库（随本模组一起分发，版本需 ≥ 1.0.1）

---

## 安装方法

1. 下载 `SuperEnergy.zip` 并解压。  
2. 将 `SuperEnergy.dll` 放入 `BepInEx/plugins` 目录。  
3. 确保 `REPO_Dinwlooc_Lib` 已安装在 `plugins` 目录。

## 功能说明

- 所有功能都只在**关卡场景（Level）**中生效，商店和主菜单不激活。

### ① 手持物品自动充电
- **效果**：玩家手持带有电池的物品（如手电筒、武器）时，自动为其充电。
- **来源选项**：
  - **Free**：免费充电，无任何消耗。
  - **Truck**：消耗卡车电量（每 10% 物品电量消耗 1% 卡车电量）。
- **可配置参数**：充电间隔（秒）、每次充电量（百分比）。

### ② 玩家自愈
- **效果**：玩家生命值低于最大生命时，自动恢复生命。
- **来源选项**：
  - **Free**：免费恢复，无任何消耗。
  - **HealthPack**：消耗附近的医疗包，总恢复量与医疗包剩余量相关。
    - > **注意**：它会不断减少医疗包内置的治疗量，并在治疗量为零时，复现其“被使用”时的一系列原版效果。
- **可配置参数**：恢复间隔（秒）、每次恢复量（HP）。

### ③ 死亡头部复活
- **效果**：玩家死亡后，激活自己的死亡头部（Spectated）时，将累积时间。达到设定值后自动复活。
- **可配置参数**：复活所需时间（秒），设为 **0** 则立即复活（无延迟）。

### ④ 体力加速恢复
- **效果**：体力值（Energy）恢复速度根据配置的百分比额外增加。
- **核心机制**：
  - 恢复速度 = **原版自然恢复速度（站立/走动）** × **（1 + 百分比/100）**，加上下蹲额外恢复的同样加成（可选）。
  - 当原版因冲刺、冷却或攀爬禁用自然恢复时，可选择是否强制补偿恢复（同样应用百分比加成）。
- **可配置参数**：
  - **百分比（0~500）**：额外恢复百分比。例如 100 表示速度为原版的 2 倍，0 表示无加成。
  - **补偿开关**：原版禁用时是否强制恢复并应用加成（默认关闭）。
  - **下蹲加成开关**：是否对下蹲/爬行的额外恢复应用百分比加成（默认开启）。
- **多人模式同步**：
  - 通过依赖库的同步缓存机制，房主可将自己的体力配置自动广播给所有客户端。
  - 开启 `UseHostConfig` 后，客户端将忽略本地配置，完全使用房主的参数（百分比、补偿开关、下蹲加成）。
  - 房主在模组加载时和每次有玩家进入关卡时自动广播，新加入的玩家也会立即收到配置。

### ⑤ 滑铲效能提升
- **效果**：延长滑铲持续时间，同时等比例降低滑铲速度衰减系数。
- > 滑铲判定只持续1s，之后体力将开始恢复。期间还可以短暂站起，之后重新下蹲就会继续滑铲，直到额外滑铲时间结束。
- **核心机制**：
  - 滑铲持续时间 = **原版默认（1.0 秒）** × **（1 + 百分比/100）**。
  - 速度衰减系数 = **原版默认（0.1）** / **（1 + 百分比/100）**。
- **可配置参数**：
  - **百分比（0~500）**：滑铲持续时间额外增加百分比。例如 100 表示滑铲持续 2.0 秒，0 表示无加成。
- **多人模式同步**：
  - 与体力配置同步机制一致，房主可将滑铲倍率广播给所有客户端。
  - 开启 `UseHostConfig` 后，客户端使用房主的滑铲倍率，忽略本地设置。

## 配置项

配置文件 `BepInEx/config/Dinwlooc.SuperEnergy.cfg` 会在首次运行后生成，可用文本编辑器或 REPOConfig 调整。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| **Enabled** | bool | true | 模组总开关 |
| **ItemCharging / Enable** | bool | true | 启用物品自动充电 |
| **ItemCharging / Source** | enum | Free | 充电来源（Free / Truck） |
| **ItemCharging / Interval** | int (1-60) | 2 | 充电检测间隔（秒） |
| **ItemCharging / Amount** | int (1-100) | 5 | 每次充电量（%） |
| **PlayerHeal / Enable** | bool | true | 启用玩家自愈 |
| **PlayerHeal / Source** | enum | Free | 自愈来源（Free / HealthPack） |
| **PlayerHeal / Interval** | int (1-60) | 2 | 自愈检测间隔（秒） |
| **PlayerHeal / Amount** | int (1-100) | 5 | 每次恢复量（HP） |
| **DeathHeadRevive / Enable** | bool | true | 启用死亡复活 |
| **DeathHeadRevive / RequiredTime** | int (0-300) | 30 | 复活所需时间（秒），0=立即复活 |
| **StaminaBoost / Enable** | bool | true | 启用体力加速恢复 |
| **StaminaBoost / Percent** | int (0-500) | 100 | 额外恢复百分比（0=无加成，100=2倍） |
| **StaminaBoost / CompensateWhenDisabled** | bool | false | 原版禁用时强制恢复并应用加成 |
| **StaminaBoost / EnableCrouchBoost** | bool | true | 对下蹲/爬行额外恢复应用百分比加成 |
| **StaminaBoost / UseHostConfig** | bool | false | 使用房主的体力配置（忽略本地设置，等待广播） |
| **SlideBoost / Enable** | bool | true | 启用滑铲效能提升 |
| **SlideBoost / Percent** | int (0-500) | 0 | 滑铲持续时间额外增加百分比（0=无加成） |

## 多人模式注意事项

- 物品充电和玩家自愈操作由**房主**执行并同步，所有玩家均生效。
- 死亡头部复活由**房主**计时，自动复活时触发 RPC 同步。
- 体力加速恢复和滑铲效能提升**仅对本地玩家有效**，不影响其他客户端（但配置可由房主统一）。
- 若开启 `UseHostConfig`：
  - **房主**：模组加载时及每次有玩家进入关卡时，自动广播当前体力配置（包含滑铲倍率）。
  - **客户端**：忽略本地 `Percent`、`CompensateWhenDisabled`、`EnableCrouchBoost` 以及 `SlideBoostPercent` 设置，等待房主广播。若未收到广播，相应功能**不会生效**，直到收到配置。
  - **单机模式**：开启 `UseHostConfig` 将自动使用本地配置（因为自身即房主），无需额外设置。

## 使用提示

- 所有功能默认启用，您可以根据喜好单独关闭任意功能。
- **Truck 模式**下请确保卡车有足够电量，否则充电会因电量不足而跳过。
- 体力加速恢复和滑铲提升仅影响**本地玩家**，多人模式下各自独立（除非开启房主配置同步）。
- 开启房主配置同步后，客户端无需手动调整，自动跟随房主设置，适合团队协作。
- 若在单机模式开启房主配置同步，效果等同使用本地配置，不影响体验。

## 兼容性

- 所有功能均通过游戏原生 API 或公共库桥接实现，不修改游戏核心代码。
- 多人模式下，充电、自愈、复活操作由房主执行并同步，体力加速和滑铲提升仅本地生效。
- 依赖库的同步缓存采用懒加载，仅当开启房主配置时才会初始化网络同步组件，不影响未使用该功能的玩家。
